# Personal Website

Zhenchang Min 的个人主页。本仓库是一个**无框架、无构建步骤**的静态学术风格网站，可直接部署到 GitHub Pages。

## 设计原则

- 内容优先：简短自我介绍、当前研究、精选项目、研究之外的兴趣和联系方式。
- 浅色背景、窄正文栏、普通文字链接；不使用卡片、动画或深色主题。
- 不把正在进行的研究写成论文，也不放没有实际成果的 Publications 占位栏目。
- 中英文切换是唯一需要的交互，默认英文，并兼容旧站的语言偏好。
- 在手机和桌面上都能自然阅读。

## 本地预览

直接在浏览器中打开 `index.html`，或在此目录运行：

```bash
python -m http.server 8000
```

然后访问 `http://localhost:8000`。推送到 GitHub Pages 后可继续使用原有仓库地址，部署前先在本地检查。

## 编辑指南

| 内容 | 文件 |
| --- | --- |
| 姓名、学校、介绍、研究、项目及链接 | `index.html` |
| 宽度、字距、颜色、响应式布局 | `css/style.css` |
| 语言切换及站点描述 | `js/main.js` |
| 头像 | `assets/avatar.jpg` |

每段双语文案同时更新 `data-en` 和 `data-zh` 以及元素中的英文默认文本，确保不开启 JavaScript 时仍能阅读。

正式发表论文后可以新增 **Publications** 栏目，给出标题、作者、发表信息以及可公开访问的论文链接。不要提前放空模板或虚构成果。
